# LASSO Research Workflow Skill

This reusable Codex skill supports the Rwanda SME fragility research project in `D:\Research\LASSO`.

Use it when continuing the project scan, raw-data audit, Stata/Python reruns, Paper 1 or Paper 2 manuscript updates, APA 7 checks, reproducibility documentation, or GitHub backup work.
